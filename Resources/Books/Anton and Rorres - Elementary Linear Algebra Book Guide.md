- Try a problem before consulting an answer.
- Record useful problem references in the matching topic folder, such as `Resources/Gaussian Elimination/`.
- Include the book section and exercise number when asking for help; this avoids edition and page-number confusion.
- Add a short worked note only for a problem you need to revisit, rather than transcribing entire chapters.
